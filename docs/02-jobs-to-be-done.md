# 2. Jobs to be done

## 2.1 Find translations in closely-related languages

> When I'm translating, show me translations that exist in closely-related
> languages without making me find them, so that I can assess whether they are
> helpful to me.

The assessment stays with the translator. RLR's obligation is that the candidate
set arrives unbidden and is honestly described.

## 2.2 Understand translation trust and access

> For a translation in a related language, help me understand what it is, who
> produced it and when, whether I can trust it, and whether/how I can legally
> use it (license).

This is a job in its own right, not a metadata field. Provenance, date,
producing organization and license terms are part of the answer RLR returns.

## 2.3 Consult an existing translation of a specific verse in a related language

> When I'm translating a verse, show me translations for the same verse in
> closely-related languages to guide my translation process, without requiring
> me to know how to find or access them.

Unit of retrieval is verse first, pericope after — see
[05-design-rationale.md](05-design-rationale.md).

## 2.4 Consult an existing translation of a specific verse in a LWC

> When I'm translating a verse, show me translations for the same verse in a LWC
> that I'm familiar with, without requiring me to know how to find or access
> them. Let me know if no such translations are available.

The final sentence is a requirement: absence must be reported, not rendered as
an empty result.

## 2.5 Consult translation resources from English in a LWC

> When I'm translating a verse or passage, find translation resources for the
> same passage that can be automatically translated into a LWC that I'm familiar
> with. Let me know if no such translations are available.

Same requirement on absence.
